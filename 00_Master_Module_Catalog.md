## 3. Relationship Summary

### 3.1 Core Business Graph

```
Company (1) → (many) Users
Company (1) → (many) Clients
Client (1) → (many) Contacts (ClientContact)
Client (1) → (many) Invoices
Client (1) → (many) Payments
Client (1) → (many) Quotes
Client (1) → (many) Credits
Client (1) → (many) Expenses
Client (1) → (many) RecurringInvoices
Client (1) → (many) Subscriptions
Client (1) → (many) Tasks
Client (1) → (many) PurchaseOrders (via Vendor)

Invoice (1) → (many) Payments  (M:N via Paymentable)
Payment (1) → (many) Invoices  (M:N via Paymentable)
Payment (1) → (many) Credits    (M:N via Paymentable)

Quote (1) → (1) Invoice       (conversion)
Invoice (1) → (1) Credit      (credit note generation)
RecurringInvoice (1) → (many) Invoices (generated instances)

Invoice (1) → (many) InvoiceItems (line_items JSON array, processed)
Client (1) → (many) Products (owned)
Vendor (1) → (many) PurchaseOrders
Vendor (1) → (many) Expenses
```

### 3.2 Settings Hierarchy (cascade: Company → GroupSetting → Client → Invoice/Client-specific override)

```
Company.settings (base defaults)
  └─ GroupSetting.settings (group override)
       └─ Client.settings (client override)
            └─ ClientContact.settings (per-contact)
```

> **Source:** `app/Services/Client/MapSettings.php`, `app/Models/Client.php` — settings are merged at runtime via `getMergedSettings()`.

> **Source:** `routes/api.php` lines 274–295, `app/Services/EDocument/`, `app/Services/Invoice/InvoiceService.php` (`sendVerifactu`, `cancelVerifactu`, `modifyVerifactuWorkflow`)

| Feature | Trigger | Description |
|---|---|---|
| **Verifactu (Spain AEAT)** | Invoice creation/sending | `SendToAeat` job dispatched; F1 document type for new invoices |
| **Verifactu Cancellation** | Invoice cancellation | R1 (partial rectification) or R2 (full cancellation) document type |
| **Verifactu Rectification** | Invoice modification | Links child invoices to parent; tracks child_invoice_ids |
| **France Payment Application Recorder** | Payment application | Records payment application dates for French regulatory compliance |
| **Peppol e-invoicing** | Invoice sending | Peppol network discovery and e-document creation |
| **France Reporting** | Enabled via `france_reporting_enabled` setting | Tracks payment application date changes via `FrancePaymentApplicationRecorder` |
