# M0 — Foundations (settings framework, numbering, tax status, i18n, retention)
**Scope** (`CC-RA-1`, `BK-001`, `BK-005`, `BK-028`, sheet `settings.md`): parameterised settings row + enumerated-value lists; numbering per entity with editable pattern/prefix and a gap register; TVA status `taxable/exonéré/franchise` on documents & lines with official DICP sentence reach (PDF/reports); company fields surfacing (timezone, footer, security settings); retention lock configurable default 10 y **[VALIDATE LOCALLY OQ-005/006]**; en-GB i18n keys alongside fr.
**Prerequisites**: none for T-001/T-003; T-002 blocked-partially by accountant confirmation of wording (build behind a flagged setting), T-009 same.
**Steps**: 1) extend schema with per-entity number settings + `number_gaps` register + TVA status columns (nullable default taxable) — migration additive only; 2) port `nextNumber` to accept per-entity pattern/prefix (register stays atomic); 3) write the register/gap UI read-only view; 4) add TVA-status derivation in `computeTotals` consumers (exempt lines emit no 0-rate bucket; franchise sentence from setting); 5) surface timezone/footer/security settings in `SettingsPage`; 6) add retention purge-guard on deletes of issued docs (OQ-005/006 — issued documents never deleted, only cancelled; lock configurable); 7) en-GB message file.
**Parameterisation (R-A)**: patterns/prefixes/thresholds/reminders wording/security limits = settings; why-in-code list: transition guards, atomic counter increment, rounding functions (`16-hardcoding-audit.md` items 14-15).
**Screens**: settings tabs (admin-editable, non-admin read-only View = R-B), number-register read-only view.
**Permissions (R-C)**: settings.write for edits (`settings.read` to view); numbering register read for accountants.
**Data/migration**: additive columns with defaults; existing sequences preserved; no destructive change (rollback = column removal before data entry).
**Tests**: number continuity incl. year rollover; gap-register row on delete of draft/issued-per-policy; status buckets (exempt line → no 0% bucket; franchise sentence on invoice PDF/export); XPF rounding cases; timezone switching behaviours; purge-guard refusals.
**Acceptance criteria** (from audit BK-001/BK-005): GIVEN exempt line WHEN printed THEN no 0% bucket; GIVEN franchise company WHEN invoice prints THEN official sentence; GIVEN deleted invoice number WHEN register opens THEN gap with reason/user; GIVEN XPF amounts WHEN computed THEN zero decimals, half-away rounding.
**Risks/rollback**: regulatory wording pending confirmation (flagged setting, not legal claim); rollback = drop additive columns pre-deployment.
**DoD**: all T-001/002/003/009 gates + module gate incl. regression; report written.
